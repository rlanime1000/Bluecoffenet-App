# کافی نت آبی – اپ اندروید (bluecoffenet.ir)

## ساخت APK
1. Android Studio (نسخه‌ی جدید) را نصب کنید.
2. File > Open و پوشه‌ی BlueCoffeNet را باز کنید و صبر کنید Gradle سینک شود.
3. Build > Build Bundle(s) / APK(s) > Build APK(s)
   خروجی: app/build/outputs/apk/debug/app-debug.apk
4. برای انتشار: Build > Generate Signed Bundle / APK و ساخت Keystore شخصی.

## امکانات
نمایش کامل سایت، کشیدن برای رفرش، نوار پیشرفت، صفحه‌ی خطای آفلاین با تلاش دوباره،
دکمه‌ی بازگشت، آپلود فایل، دانلود فایل، باز شدن لینک‌های خارجی در مرورگر،
و باز شدن لینک‌های bluecoffenet.ir داخل اپ. تم آبی و سفید.

## شخصی‌سازی
- آدرس: HOME در MainActivity.java
- رنگ‌ها: res/values/colors.xml
- آیکون: res/drawable/ic_launcher_foreground.xml
